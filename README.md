## Scene 1 - Build A Burger
This is a scene where the player will walk up to a desk that contains ingredients for assembling a burger, and the burger can be assembled by picking up the ingredients and snapping them to each of the provided ghost targets (colored to try and lessen visual clutter). The player is also given directions on how to assemble the burger.

I spawned the player character in front of the desk that we will be building the burger on, but for some reason I couldn't get the spawn point to immediately face the desk, so the player will just have to turn around at the beginning.
